
# Online Bookstore Management
## Project Description
Online Bookstore Management is a software application developed to manage
online book purchasing and bookstore-related activities. The system aims
to provide a convenient platform for users to browse books, view details,
and manage their purchases.

- Browse available books
- Search for books
- View book details
- Add books to cart
